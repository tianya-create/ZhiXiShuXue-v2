# 三分钟项目介绍稿：知识追踪模型与稀疏图结构的受控实证研究

> 用途：科研保研 / 面试口播。全文约 850 字，正常语速 2 分 50 秒左右。
> 口径与简历表述一致：构建 → 设计 → 完成 → 发现 → 分析限制。

---

各位老师好，我介绍的项目是「知识追踪模型与稀疏图结构的受控实证研究」。

在线学习系统要给学生推荐练习，首先要知道"学生现在会不会"，也就是知识追踪——根据学生的历史答题记录，预测他下一次答题的对错。这个项目做的问题是：**在知识点关系图的帮助下，图神经网络知识追踪能不能预测得更准？**

我在自己开发的教学平台上，基于公开的 ASSISTments 2009 数据集——26 万多条交互、近 4000 名学生、100 个知识点——构建了一个完整的实验体系。模型上，我从规则掌握度公式出发，到贝叶斯知识追踪 BKT，再到循环神经网络 GRU-DKT，最后是图卷积增强的 GCN-DKT，形成一条完整的演进链。每一级都有明确提升：GRU-DKT 的 AUC 达到 0.744，显著优于 BKT 的 0.716 和规则的 0.701。

为了回答图结构有没有用，我设计了三层受控证据。**第一层是输入消融**：分别只保留同一知识点的历史、打乱历史中的知识点标签、完全去掉对错信号，结果发现对错历史是最主要的预测信号，去掉它 AUC 掉了接近 7 个点，而且五次重复全部显著。**第二层是五组图对照**：真实共标注图、同等规模的随机图、只有自环的图、加大容量的对照组，加上无图的基线，在五个随机种子上共完成 25 次正式训练。**第三层是统计和审计闭环**：学生级配对 bootstrap 给出置信区间；一个不加载模型的独立审计程序，从落盘的预测文件重新计算全部指标逐项核对；聚合程序还内置了四道数据完整性闸门，防止任何结果被事后修改。

结论是诚实的否定：**GCN-DKT 相对无图基线的平均 AUC 差是负的千分之七，五个种子里只有一个为正，没有一个种子的置信区间支持它；真图和随机图、自环图没有可靠差异，容量对照也排除了"参数不够"的解释。**我进一步分析了原因：这张图 100 个节点里有 64 个是孤立的，大约一半的测试目标根本不在有边的节点上；而学生序列长度的中位数只有 6，循环网络已经把序列里的信号用得比较充分了。所以这是一个**有条件的否定**——在稀疏图、短序列的场景下，不应该默认上图结构；我把它作为单一数据集、单一图构造下的结论，明确写了外推边界。

这个项目给我的最大收获是：**负面结果只有配上严格的受控设计和独立审计，才有科学价值**。后续我计划把无图的最强基线接入平台推荐模块做评估，并在知识点规模更大的 Junyi 数据集上检验图增强是否在其他条件下成立。

谢谢各位老师。

## 可能的追问与要点（备答）

1. **"结论是负的，你的贡献是什么？"** —— 贡献不在"图有效"而在"可信地证明它在本条件下无效"：冻结协议防事后调阈值、25 次完整拟合、独立审计 164 项 × 5 种子全过、输入消融定位了信号来源，这套方法论本身是可迁移的。
2. **"为什么只跑 5 个种子？"** —— 每个种子是一次完整的独立划分+训练；判定规则（4/5 方向 + 3/5 CI 支持）在见测试数据前冻结，结论措辞明确不声称统计等价。
3. **"怎么防止你调参调出来的结果？"** —— 超参与筛选阈值在实验配置里冻结并有哈希指纹，任何实现或数据变动都会使缓存整体失效；审计器与聚合器独立于训练代码。
4. **"下一步？"** —— Full-DKT 进推荐模块基线评估；Junyi / ASSIST2012 跨数据集；如做更大知识点体系，图覆盖率是首要检查项。
