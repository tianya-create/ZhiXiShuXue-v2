## 0. 为什么要补这一节

原备忘的 stop 判定建立在一个端点之上：**全部 36,967 个目标上的 ΔA = −1.73e-4（0/5 正向）**。这个数有一个可被审稿人一击的弱点：

覆盖率只有 **17.9%**，也就是说 82% 的目标上先修特征全为缺失（`nb_missing = 1`）。这些行的 Δ 被结构性压到接近 0，整体端点因此被稀释约 **5.6 倍**。审稿人只需问一句「你是不是把一个可能存在、但只作用在 18% 样本上的效应稀释掉了」，原结论就得重新解释。

本补充只做一件事：**在没有稀释的子群上重算同一个端点，并加上随机特征的对照**。结论是 stop 判定成立，而且比原备忘更硬。

---

## 1. 方法与复现校验

- 事后（post-hoc），发生在冻结判定之后；不修改 `priorSignalProbe.js`、不改阈值、不换超参、不重训新模型；
- 完全 `require('./priorSignalProbe')` 复用其中纯函数（`computeTargetFeatures` / `groupKFold` / `fitScaler` / `transformRows` / `trainLR` / `predictLR` / `logLossOf`）与同一 `foldSeed`，因此折划分、标准化、缺失策略与主实验逐项一致；
- **内置复现校验**：脚本先算整体 ΔA 与 ΔA|B，必须与 `probe.json` 的 `perSeed` 逐位一致（容差 1e-9），否则抛错退出。实测五种子全部通过，整体 ΔA 均值 −1.733e-4 与备忘完全相同；
- 子群定义：`nb_missing = 0`，即该目标之前学生已练过至少一个先修邻居。A 组与 C 组各按自己的掩码算，互不混用。

复现命令：

```
cd backend
node models/priorProbeSubgroup.js \
  --input-dir 实验结果文件/gcn-dkt-v1 \
  --interactions datasets/assist2009/interactions.csv \
  --prior-edges datasets/assist2009/prior-edges.csv \
  --config 实验结果文件/prior-probe-v1/probe-config.json \
  --probe 实验结果文件/prior-probe-v1/probe.json \
  --out 实验结果文件/prior-probe-v1/subgroup-posthoc.json
```

## 3. 三条解读

### 3.1 稀释假设成立，且稀释的是「负效应」

整体 −1.73e-4 与子群 −9.42e-4 的比值正好等于覆盖率 1/5.57。这证实整体端点的接近零是**结构性稀释**的结果，不是效应本身为零。子群标准差 6.8e-4 也回到了阶段 E 实测的 ±1e-3 噪声带，而整体端点的标准差只有 1.2e-4——方差本身就在告诉你，有效样本是那 18% 而不是全部。

所以结论不是"没找到"，而是"**在能用到先修信息的地方，加进去反而更差**"。

### 3.2 先修特征与随机特征不可区分——这才是最关键的一行

ΔA 子群 −9.419e-4 对 ΔC 子群 −9.259e-4，差 **1.6e-5**，远小于两者各自 6e-4 量级的标准差。也就是说，**一版按教材语义认真抽取的先修边，和一堆随机连起来的边，对模型的信息价值没有区别**。

这一行同时排掉了一个常见的辩解：「信号可能存在，只是被正则不足压住了」。若先修特征真有信息，它退化得应当比随机特征**更少**，甚至转正；实测是退化得一样多。退化的来源是参数增加而非信号缺失——和阶段 E 里 GCN 相对 Full 的 −7.4e-4 是同一类现象。

### 3.3 更深的原因：这组特征在构造上就是序列内部信息

这一点值得单独写进论文，因为它解释了为什么换数据集也可能白做。

子群里的六项邻居特征——`nb_cov`、`nb_recent_acc`、`nb_last_correct`、`nb_gap_log`、`nb_recent20`、`nb_attempts`——**全部是"同一个学生在相邻知识点上的历史作答"的重新聚合**。而 DKT 的输入就是这名学生的完整作答序列，它已经看过这些交互。

所以这个探针实际检验的是：**把学生自己的邻居知识点历史显式聚合一遍，能不能超过 RNN 的隐式表示**。在序列中位数只有 6 步的数据上，答案必然是否。真正"序列之外"的信息——教材层级、题目难度参数、跨学生的先修掌握约束——在 ASSIST2009 里根本不存在。

这带来一个比"覆盖率不足"更硬的结论：

> 在这个数据集上，能够被操作化的"先修信息"，全部是学生自身历史的重述；DKT 已经吸收。唯一真正外部的只有图拓扑本身，而图拓扑在 42 条边、46% 孤立节点的条件下不可测。**因此无论换模型、换特征还是换数据集（只要新数据仍只有作答序列），都不会有增量。**

## 4. 对原备忘措辞的两处修订建议

| 原表述 | 建议改为 |
|---|---|
| 「ΔA 五种子全部为负（mean −1.73e-4，0/5 正向）」 | 保留，但补一句「整体端点受 82% 空特征稀释；子群端点 −9.42e-4（0/5）才是未稀释值」 |
| 「先修关系对目标正确率没有可检出的增量预测力」 | 「以学生自身先修练习史为载体的先修信号，在序列模型之上无可检出的增量，其效应与随机邻居不可区分」 |

第二处的差别不是文字游戏：前者是对"先修关系"这个科学命题下判断，后者只对"这一种操作化方式"下判断。在人工核验尚未完成、边质量未知的前提下，只有后者是能站住的。

---

## 5. 对「换数据集」规则的修正

原方案 §5 写的是：先报图覆盖率与孤立节点比例，覆盖率 <40% 不做图对照。本补充要求再加一条，且它优先于覆盖率：

> **新数据集必须先回答：它有没有序列之外的信息源？** 若仍只有"学生—题目—对错"三元组（ASSIST2012、Junyi 的作答日志部分），无论图多密、覆盖率多高，重演的概率都很高。只有当数据集附带层级化知识点体系、题目难度/区分度参数、或跨学生的先修掌握约束时，图增强才有可挖的增量。

---

## 6. 人工核验的真实作用

原备忘说「即使核验不达标也只会加强无信号结论，不会翻盘」。这句对**决策**成立，对**论文措辞**不成立，需要写清：

- 若 precision ≥ 0.75 且 κ ≥ 0.60：可以主张「即使边是对的，先修信息在序列模型之上仍无增量」——这是强命题；
- 若 precision < 0.75：只能说「LLM 抽取的这一版先修边与随机边不可区分」——弱命题，且"与随机不可区分"变成对边质量的描述，而不是对先修关系的描述。

所以核验不是归档性待办，它决定论文能不能用强命题。建议仍按方案 §2.4 做完。

---

## 7. 结论

**stop 判定成立，且证据链比原备忘完整：**

1. 未稀释的子群端点为 −9.42e-4（0/5 正向），方向明确为负；
2. 与随机特征对照（−9.26e-4）不可区分，排除了「信号被正则压住」的辩解；
3. 机制上，这组特征与 DKT 输入同源，结构上不可能提供增量；
4. 三条独立证据（阶段 E 图对照 −7.4e-4、分层九桶无一稳定正、残差探针 −9.4e-4）指向同一结论。

下一步按备忘：终止 KT 图增强线，三份材料合成一篇负结果实证；主线回 SLAM，或转教育资源构建（抽取协议与核验表可复用）。
