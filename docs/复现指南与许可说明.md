# 复现指南与许可说明（知识追踪受控实证研究）

对应研究：《知识追踪模型与稀疏图结构的受控实证研究》（`docs/知识追踪模型与稀疏图结构的受控实证研究.md`）。

## 1. 环境

| 项 | 值 |
|---|---|
| 运行时 | Node.js ≥ 22.13（实验实际使用 **v22.22.2**，win32 x64；后端依赖内置 `node:sqlite`） |
| 测试框架 | Jest（`backend/test/`，16 套件 232 用例全过） |
| 深度学习实现 | 纯 Node.js 手写前向/反向（`dkt.js` 数值路径与梯度累计行为锁定，无 Python 依赖） |
| 随机性 | 每实验一个 `--seed` 同时控制学生划分、参数初始化与训练随机流；图随机化种子由固定哈希派生 |
| 代码版本 | 阶段 D：`58ec8a3`；阶段 E 报告：`80618dc`（远程 v2/main） |

安装：仓库根目录 `npm install`（自动装 backend/frontend 依赖）。

## 2. 数据获取与许可（先读）

- **数据集**：ASSISTments 2009-2010 Skill Builder（官方页面
  `https://sites.google.com/site/assistmentsdata/home/2009-2010-assistment-data/skill-builder-data-2009-2010`）。
- **许可**：ASSISTments 数据使用协议——**限学术研究使用，成果需引用 ASSISTments 团队**。不得用于商业用途或再分发原始数据。
- **不入库**：原始 CSV（79 MB）与清洗产物（17 MB）**均不提交 git**，仓库只含 manifest 与知识点映射（见 `backend/datasets/README.md`）。复现前需自行下载数据并校验 SHA-256：
  - 原始：`skill_builder_data.csv`，SHA-256 `408698925fc3488672431e4c19b9b16808b6a25760f8e41ad4d3d6257ad0832a`
  - 任务：`interactions.csv`，SHA-256 `6f055c6b5105b8295ef8bcf9dd23c668634f56eedc4dbdcf5a8708bee0618be9`
- 引用建议：Feng, Heffernan & Koedinger (2009), *Addressing the assessment challenge with an online system that tutors as it assesses* (ASSISTments)。

## 3. 复现命令（均在 `backend/` 目录下执行）

### 3.1 数据接入与清洗

```bash
node scripts/ingest-assistments2009.js          # 生成 datasets/assist2009/interactions.csv + manifest
```

### 3.2 模型演进链（每个种子一条命令，seeds 42–46）

```bash
# 规则 / Majority 基线（不含模型训练）
node models/baselineEval.js --source csv --file datasets/assist2009/interactions.csv \
  --bootstrap 2000 --label assist2009

# BKT（同协议参数与 baselineEval 一致）
node models/bktEval.js --source csv --file datasets/assist2009/interactions.csv \
  --bootstrap 2000 --label bkt-assist2009 --models "BKT,Rule-0,Majority"

# GRU-DKT（--seed 42..46 各一次）
node models/dktEval.js --source csv --file datasets/assist2009/interactions.csv \
  --bootstrap 2000 --label dkt-assist2009 --seed 42
```

### 3.3 输入消融（Same-KP / Shuffled-KP / NoResponse，每种子一次）

```bash
node models/dktAblation.js --source csv --file datasets/assist2009/interactions.csv \
  --seed 42 --bootstrap 2000 --label dkt-ablation-s42
# 可选超参与冻结协议一致：--epochs 50 --patience 5 --hidden 64 --embed 32 --dropout 0.2 --lr 1e-3 --batch 64
```

### 3.4 图五组对照（阶段 A 构图 → B/C/D 训练评估）

```bash
# 阶段 A：train-only 共标注图 + 随机图/自环对照（每种子）
node scripts/buildAssist2009SkillGraph.js --config 实验结果文件/gcn-dkt-v1/experiment-config.json --seed 42

# 阶段 C：冒烟（限定 seed 42、仅 train/validation，非正式）
node models/graphDktExperiment.js --stage smoke \
  --config 实验结果文件/gcn-dkt-v1/experiment-config.json \
  --prepared-dir 实验结果文件/gcn-dkt-v1/seed-42

# 阶段 D：正式训练（五组一次性完整拟合，每种子；产物落盘 + 缓存指纹）
node models/graphDktExperiment.js --stage train --seed 42 \
  --config 实验结果文件/gcn-dkt-v1/experiment-config.json \
  --prepared-dir 实验结果文件/gcn-dkt-v1/seed-42

# 只读重算（不补训）
node models/graphDktExperiment.js --stage evaluate --seed 42 \
  --config 实验结果文件/gcn-dkt-v1/experiment-config.json \
  --input-dir 实验结果文件/gcn-dkt-v1

# 统计修订（复用 predictions 重算，不重训；--reason 必填留痕）
node models/graphDktExperiment.js --stage restat --seed 42 --reason "<修订原因>" \
  --config 实验结果文件/gcn-dkt-v1/experiment-config.json \
  --input-dir 实验结果文件/gcn-dkt-v1
```

### 3.5 独立审计与五种子聚合

```bash
# 逐种子独立审计（不加载模型，从 predictions 重算，164 项校验）
node models/auditGraphDktResults.js --config 实验结果文件/gcn-dkt-v1/experiment-config.json \
  --input-dir 实验结果文件/gcn-dkt-v1/seed-42 --seed 42

# 五种子聚合（内置四道闸门：results 哈希 / 标志自洽 / 未复算 CI / 统计实现哈希）
node models/aggregateGraphDktSeeds.js --config 实验结果文件/gcn-dkt-v1/experiment-config.json \
  --input-dir 实验结果文件/gcn-dkt-v1 --seeds 42,43,44,45,46
```

### 3.6 测试

```bash
cd backend && npm test     # 16 套件 232 用例
```

## 4. 结果文件与哈希

- 逐种子产物：`backend/实验结果文件/gcn-dkt-v1/seed-{42..46}/`（targets / predictions / curves / results / audit-report）；
- 聚合：`multiseed-summary.json`（含未舍入重算口径 `perSeedExact` 与四项比较）；冻结配置：`experiment-config.json`；
- 每份 results.json 记录数据/划分/图/实现哈希；审计报告绑定 `resultsSha256`；统计实现哈希五种子一致（`ebbcb582…`）。
