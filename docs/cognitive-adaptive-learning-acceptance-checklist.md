# 智析数学认知—心理双层适配功能验收清单

> 适用版本：认知—心理双层学情适配 V2.0  
> 验收方式：在每项前勾选；任何一项失败时记录“用例编号、账号、知识点、操作步骤、截图”。

## 一、验收环境与账号

### 1. 启动系统

在项目根目录执行：

```bash
npm run dev
```

- 前端地址：`http://localhost:5000`
- 后端健康检查：`http://localhost:5001/api/health`

### 2. 开发环境演示账号

| 角色 | 用户名 | 密码 |
| --- | --- | --- |
| 管理员 | `admin` | `admin123` |
| 教师 | `teacher` | `teacher123` |
| 学生 | `student`、`student2`～`student10` | `student123` |

建议使用不同学生账号分别验收单一 VARK、混合 VARK、未完成轮次和不同难度判定，避免历史数据互相影响。

### 3. 前置数据

验收前由教师或管理员确认：

- [ ] 测试学生已加入教师所教班级。
- [ ] 班级已学范围包含待测知识点。
- [ ] 整式、整式加减、分式与分式运算或一元一次方程中，至少有 5 道已审核可用题。
- [ ] 5 道题的标准答案已知，方便构造 `2/5`、`3/5`、`4/5`、`5/5` 等正确率。
- [ ] 题目分别准备低、中、高认知负荷样本，并填写部分精简题干和分步提示。

## 二、15 分钟核心闭环验收（P0）

### AC-01 首次进入薄弱补练

操作：

1. 使用一个从未测评过的学生账号登录。
2. 进入“薄弱补练”，选择白名单知识点，如整式或一元一次方程。

通过标准：

- [ ] 先弹出学习偏好问卷，题目不能提前显示。
- [ ] 问卷没有关闭按钮，点击遮罩和按 `Esc` 均不能跳过。
- [ ] 未完成 12 题时点击提交，提示仍有题目未选择，不能提交空问卷。

### AC-02 VARK 结果先展示再做题

操作：完成 12 道 VARK 题并提交。

通过标准：

- [ ] 提交后先显示本周偏好结果，而不是立即显示习题。
- [ ] 结果包含偏好名称、图标、说明和将采用的资源形式。
- [ ] 学生点击“开始本轮薄弱补练”后，才加载题目。
- [ ] 页面恰好出现同一知识点的 5 道题。

### AC-03 五题完整提交与轮后自评

操作：先只完成 4 题点击“交卷批改”，再完成第 5 题提交。

通过标准：

- [ ] 4/5 时提示“还有题没做完”，不允许提交，也不弹出自评。
- [ ] 5/5 时提交成功，并弹出轮后自评。
- [ ] 自评包含表情、两道学业控制感题和一道主观认知负荷题。
- [ ] 任一项未选择时不能提交；弹窗不能通过遮罩、`Esc` 或关闭按钮跳过。

### AC-04 学生隐私与心理便利贴

操作：完成轮后自评并提交。

通过标准：

- [ ] 学生进入“本轮学习反馈”页。
- [ ] 学生只能看到普通的下一轮安排，不显示“低/中/高控制感”、控制感总分、Q1/Q2 原始分。
- [ ] 页面出现带表情的便利贴式鼓励文案。
- [ ] 便利贴文案与本次感受匹配，可手动关闭，不遮挡下一轮按钮和核心内容。
- [ ] 页面显示下一轮复杂度、页面密度和资源呈现偏好。

### AC-05 下一轮联动

操作：在反馈页点击“进入下一轮”。

通过标准：

- [ ] 返回同一知识点的下一轮 5 题。
- [ ] 任务复杂度、分步支架和页面信息密度与反馈页给出的安排一致。
- [ ] 页面自动加载该学生的 VARK 资源风格。
- [ ] 7 天有效期内再次进入不重复弹出 VARK 问卷。
- [ ] 每完成一个新的有效 5 题轮次，仍会再次弹出学业控制感自评。

## 三、VARK 学习偏好验收

### AC-06 单一偏好

建议数据：V 的 3 题全部选 5；A、R、K 全部选 1。

通过标准：

- [ ] 结果为单一“视觉型 V”。
- [ ] 只启用一个主资源通道。
- [ ] 视觉页面突出关系图、结构和颜色线索，明显区别于另外三种样式。

### AC-07 双偏好混合

建议数据：V、K 的题全部选 5；A、R 全部选 1。

通过标准：

- [ ] 最高分与第二名差值为 0，结果为 `V + K` 混合偏好。
- [ ] 结果页同时显示两类偏好。
- [ ] 练习页同时提供图示关系资源和练习试错通道。
- [ ] 双通道没有改变第一层已经确定的任务难度。

### AC-08 混合判定边界

- [ ] 第一、第二名差值 `<= 0.5` 时判定为混合偏好。
- [ ] 差值 `> 0.5` 时只保留最高分偏好。
- [ ] 三项或四项同分时最多保留两个偏好，不生成三通道或四通道。
- [ ] 完全同分时结果顺序稳定，按 `V → A → R → K` 取前两名。

### AC-09 四类页面明显区分

分别用四个学生账号制造 V、A、R、K 单一偏好。

| 偏好 | 通过标准 |
| --- | --- |
| V 视觉型 | 显示关系图/结构图，减少连续大段文字 |
| A 听觉型 | 显示“播放思路旁白”，能播放/停止中文步骤旁白 |
| R 阅读书写型 | 显示概念、规则、表达等规范文字层级 |
| K 动觉实操型 | 前置讲解精简，突出先作答、试错和即时反馈 |

### AC-10 七天缓存与复测

- [ ] 完成测评后退出登录，再登录进入白名单薄弱补练，7 天内不重复测评。
- [ ] 接口或记录中的 `validUntil` 等于完成时间后 7 天。
- [ ] 使用一条 `validUntil` 已过期的测试账号进入时，重新强制弹出问卷。
- [ ] 复测产生新历史记录，旧记录仍保留，不覆盖原始答案。
- [ ] 管理端备份数据中的 `learnerPresentationProfiles` 保存 12 道原始答案、V/A/R/K 分数、单/双偏好和完成时间。

## 四、五题有效轮次与数据一致性

### AC-11 中途退出无效

操作：在白名单薄弱补练中完成 1～4 题后直接离开页面，再重新进入。

通过标准：

- [ ] 未触发轮后自评。
- [ ] 不生成正式学习轮次和控制感记录。
- [ ] 不更新难度决策、学习轨迹和教师统计。
- [ ] 返回后不恢复这轮未完成的答案。

### AC-12 固定五题与同知识点

- [ ] 每个自适应任务包固定为 5 题。
- [ ] 5 题属于同一个知识点。
- [ ] 非 5 题提交被服务器拒绝，不产生部分正式数据。
- [ ] 混入其他知识点题目时被服务器拒绝。

### AC-13 幂等提交

操作：在网络面板中对同一提交请求使用相同 `requestId` 重放一次，或模拟超时后重试。

通过标准：

- [ ] 返回同一个学习轮次。
- [ ] 不重复计分、不重复更新画像、不新增第二条控制感记录。

## 五、难度判定规则验收

准备初始复杂度为“中”的 5 题任务包，按下表制造答题结果和自评。

| 用例 | 正确数 | Q1+Q2 | Q3 | 预期 |
| --- | ---: | ---: | ---: | --- |
| AC-14 | 0～2/5 | 任意 | 任意 | 正确率 `<60%`，下一轮降一级 |
| AC-15 | 3/5 | 非低+高负荷强制组合 | 任意 | 正确率 `60%`，难度维持 |
| AC-16 | 4/5 | 非低+高负荷强制组合 | 任意 | 正确率 `80%`，难度维持 |
| AC-17 | 5/5 | 5～10 | 1～3 | 正确率 `>80%`，下一轮升一级 |
| AC-18 | 5/5 | 2～4 | 4～5 | 低控制感 + 高主观负荷，强制降一级，覆盖高正确率 |

附加边界：

- [ ] Q1+Q2 为 2～4 判为低，5～7 判为中，8～10 判为高。
- [ ] Q3 为 1～2 判为低，3 判为中，4～5 判为高。
- [ ] 每轮最多升降一级。
- [ ] 已是低复杂度时继续降级仍保持低；已是高复杂度时继续升级仍保持高。
- [ ] 高控制感本身不会强制升级，仍以正确率为准。

### AC-19 难度变化与视觉密度同步

降级通过标准：

- [ ] 下一轮优先低认知负荷题、精简题干和分步小题。
- [ ] 页面增加留白、减少并列信息，自动展开更强的分步提示。

维持通过标准：

- [ ] 题目保持当前复杂度和标准页面布局。

升级通过标准：

- [ ] 下一轮为同知识点变式或迁移题，复杂度最多提高一级。
- [ ] 完整展示题干，适度减少提示。

## 六、题库与配置验收

### AC-20 题目认知负荷字段

操作：教师进入“题目管理”或管理员进入“题库管理”，编辑一题。

通过标准：

- [ ] 可选择低、中、高认知负荷。
- [ ] 可填写低信息密度题干和高支架拆解步骤。
- [ ] 保存并刷新后数据仍在。
- [ ] 可按认知负荷筛选题目。
- [ ] 历史未标注题目按中负荷兼容处理。

### AC-21 管理员规则配置

操作：管理员进入“系统设置 → 认知—心理适配参数”。

通过标准：

- [ ] 可启用或关闭双层适配。
- [ ] 固定显示每轮 5 题、VARK 有效期 7 天。
- [ ] 可配置控制感、主观负荷、正确率阈值和规则版本。
- [ ] 非法阈值组合保存时给出明确错误。
- [ ] 保存后刷新仍保留，后续决策记录带对应规则版本。

## 七、教师端与管理端验收

### AC-22 教师班级统计

操作：学生完成 VARK 和至少一轮自评后，教师登录进入“首页概览”。

通过标准：

- [ ] 显示学业控制感低/中/高分布。
- [ ] 显示低/中/高认知负荷分布。
- [ ] 显示 V/A/R/K 资源偏好分布。
- [ ] 只统计该教师所教班级。

### AC-23 教师查看单个学生

操作：进入“学情分析 → 学生学情”，选择刚才的学生。

通过标准：

- [ ] 显示当前单一或混合 VARK 偏好。
- [ ] 显示每轮控制感等级和总分。
- [ ] 显示主观认知负荷等级和分数。
- [ ] 显示历史记录且时间顺序正确。
- [ ] 教师尝试访问其他教师班级学生时被拒绝。

### AC-24 管理员统计与学生历史

操作：管理员进入“数据统计”，再进入“用户管理 → 学生 → 适配记录”。

通过标准：

- [ ] 数据统计显示全校控制感、题目认知负荷、VARK 分布。
- [ ] 用户适配记录显示当前 VARK 标签和有效期。
- [ ] 显示该生每轮控制感结果和主观负荷结果。
- [ ] 新完成一轮后刷新，统计数字和历史记录同步增加。

### AC-25 学生端隐私隔离

- [ ] 学生端页面和接口不返回控制感总分、等级、Q1/Q2 原始答案。
- [ ] 学生不能查看其他学生的自评和偏好记录。
- [ ] 教师只能查看自己班级；管理员可以查看全部班级。

## 八、生效范围与原功能回归

### AC-26 白名单范围

在以下知识点进入薄弱补练，应启用双层适配：

- [ ] 整式 `alg-1`
- [ ] 整式加减 `alg-2`
- [ ] 分式与分式运算 `algebra-3`
- [ ] 一元一次方程 `alg-3`

选择几何等白名单外知识点：

- [ ] 不弹出本机制专属 VARK 和控制感问卷。
- [ ] 沿用原有题目推送与页面样式。

### AC-27 普通作业交卷回归

操作：教师发布一份 5 题普通作业，学生进入“我的作业”。

通过标准：

- [ ] 普通作业答 4/5 后，经二次确认可以交卷；它不受薄弱补练“必须 5 题”的规则影响。
- [ ] 提交成功后自动进入答卷结果页。
- [ ] 再次直接打开同一作业作答地址时，自动进入已有答卷，不再出现笼统的“提交失败”。
- [ ] 作业截止、网络断开或服务未启动时，显示具体失败原因。

### AC-28 原有功能回归

- [ ] 学生：作业、错题本、知识图谱、薄弱知识点、学习轨迹正常。
- [ ] 教师：班级、学生、题目、试卷、作业发布、批改和学情正常。
- [ ] 管理员：用户、班级、知识点、题库、统计、日志、备份恢复正常。
- [ ] 三种角色的路由权限没有串端。

## 九、长期偏好微调（数据准备用例）

### AC-29 长期效果微调

准备同一学生至少 6 个有效轮次，并使最近多轮表现持续较低。

通过标准：

- [ ] 系统保存每轮资源偏好效果证据。
- [ ] 满足条件时只增加一个接近的第二资源通道，最多两个通道。
- [ ] 不修改历史 VARK 原始答案。
- [ ] 反馈页说明这是资源呈现调整，不把它描述为能力判断。
- [ ] 教师和管理员可从历史接口追溯调整依据和时间。
