五、核心发现

① response 历史是主要预测信号（ΔAUC +0.0677，5/5 CI 显著），知识点身份与时序次之（+0.0102 / +0.0300，均 5/5）。
② 稀疏共标注图未产生稳定增益：GCN−Full 平均 −0.000742；真图 ≈ 随机图、≈ 自环，容量对照排除"参数不足"。机制：42 边 / 64 孤立节点 / 约 50% test 目标在有邻边节点上，且序列中位数仅 6，GRU 序列信号已近饱和。
③ 结论为有条件否定（单一数据集 × 单一图构造 × n=5），不外推为"图增强一律无效"；Full-DKT 进入推荐模块候选基线，不在本数据集继续调图追正结果。
