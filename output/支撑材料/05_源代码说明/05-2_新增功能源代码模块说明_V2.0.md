# 智析数学新增功能源代码模块说明

## 1 后端模块

| 文件 | 模块职责 |
| --- | --- |
| `backend/services/adaptive-learning.js` | 定义白名单、VARK 题目和计分、7 天有效期、控制感与感知负荷分级、复杂度判定、页面密度、支架和安全响应对象 |
| `backend/routes/student-adaptation.js` | 提供学生适配状态、VARK 问卷和提交、轮后自评、下一轮决策及主动求助接口 |
| `backend/routes/teacher-adaptation.js` | 提供教师班级适配概览和学生历史接口，并校验教师班级归属 |
| `backend/routes/student.js` | 组装白名单 5 题任务包，校验同一知识点和完整提交，保存有效学习轮次并更新学习数据 |
| `backend/routes/admin.js` | 提供管理端适配统计、学生档案和规则设置 |
| `backend/services/manual-question-bank.js` | 维护题目认知负荷、支架步骤和资源绑定，处理历史题默认等级 |
| `backend/services/question-quality.js` | 规范化认知负荷字段并保证题目质量校验 |
| `backend/database/memory-db.js` | 定义并持久化 VARK、自评、学习轮次、适配决策、呈现证据和主动求助集合 |

## 2 前端学生端模块

| 文件 | 模块职责 |
| --- | --- |
| `frontend/src/views/student/WeakPractice.vue` | 进入薄弱练习时检查 VARK，阻断过期用户，加载 5 题任务，提交后触发轮后自评并应用下一轮页面密度 |
| `frontend/src/components/adaptive/PracticePreferenceDialog.vue` | 展示 12 题 VARK 问卷、1 至 5 分文字说明和测评结果，要求学生确认结果后再进入练习 |
| `frontend/src/components/adaptive/AdaptiveReflectionDialog.vue` | 展示表情、控制感 Q1/Q2 和感知负荷 Q3，校验全部必填 |
| `frontend/src/components/adaptive/EmotionalStickyNote.vue` | 显示分级心理支持文案和表情，可关闭且不遮挡主要内容 |
| `frontend/src/components/adaptive/AdaptiveResourcePanel.vue` | 根据 V、A、R、K 单一或双偏好组织图示、音频、文字和实操资源 |
| `frontend/src/components/QuestionCard.vue` | 展示题目认知支架、分步提示和适配内容 |
| `frontend/src/views/student/AdaptiveFeedback.vue` | 展示轮次反馈、普通化的下一轮安排和主动求助入口，不暴露控制感等级 |

## 3 前端教师端和管理端模块

| 文件 | 模块职责 |
| --- | --- |
| `frontend/src/views/teacher/Dashboard.vue` | 展示班级控制感、题目认知负荷、VARK 分布和主动求助数量 |
| `frontend/src/views/teacher/StudentAnalytics.vue` | 展示单个学生的适配档案和历史记录 |
| `frontend/src/views/teacher/Papers.vue` | 提供试卷查看、题目管理和安全删除或归档 |

| `frontend/src/views/admin/Users.vue` | 展示学生 VARK、自评和适配决策历史 |
| `frontend/src/views/admin/Settings.vue` | 维护启用状态、白名单、阈值、有效期和规则版本 |
| `frontend/src/components/QuestionBankManager.vue` | 编辑、筛选和批量设置题目认知负荷等级 |

## 5 数据和隐私控制

学生接口使用专门的安全响应对象，不返回控制感分数、等级、原始答案或完整适配决策存储对象。教师接口校验班级归属，管理端接口校验管理员角色。所有正式问卷保存原始答案、问卷版本、完成时间和有效期，长期微调不能覆盖问卷原始记录。
