## 使用要求

1. 原型图和真实系统截图必须分开标注，不得用原型图代替实测截图。
2. 测试记录中的结果、耗时和并发数据必须来自实际执行，不填写推测值。
3. Bug 台账只登记已经复现的缺陷，并填写修复提交和回归结果。
4. 截图文件名应保留编号、浏览器、角色和页面名称，避免提交后无法对应测试项。
