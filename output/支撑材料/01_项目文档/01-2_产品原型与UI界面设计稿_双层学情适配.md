# 智析数学双层学情适配产品原型和界面设计说明

## 1 标注规则

本材料把原型示意和真实系统截图分开管理。

- 原型示意图：用于说明设计意图，文件名必须含“原型”。
- 真实系统截图：用于证明功能已经运行，统一放入 `02-3_浏览器兼容性测试截图`，文件名包含浏览器、角色和页面。

## 2 学生端页面

| 页面或组件 | 必须展示的内容 | 关键交互 |
| --- | --- | --- |
| VARK 问卷弹窗 | 12 道题、1 至 5 分完整含义、已答进度 | 未全部回答不能提交，提交失败保留选择 |
| VARK 结果卡 | 单一或双偏好名称、简要说明、资源形式 | 结果出现后点击开始薄弱练习才加载题目 |
| 白名单 5 题练习页 | 1/5 至 5/5 进度、题目、支架、资源面板 | 未答满 5 题不能提交，中途退出不保存正式轮次 |
| 轮后自评弹窗 | 表情、Q1、Q2、Q3 | 全部必填，不能通过遮罩、Esc 或关闭按钮跳过 |
| 心理便利贴 | 表情、鼓励文案、下一步建议 | 可手动关闭，不遮挡题目和按钮 |
| 适配后练习页 | 目标复杂度、页面密度、VARK 资源组合 | 低复杂度增加留白并分步，高复杂度显示完整变式 |
| 学生主动求助 | 求助按钮和简短说明 | 学生主动点击后才向教师端产生请求 |

## 3 VARK 四类界面差异

| 类型 | 主要视觉结构 | 主要资源 |
| --- | --- | --- |
| V 视觉型 | 图示区域位于题干之前或侧边，文字控制在短段落 | 思维导图、知识关系图、步骤示意图 |
| A 听觉型 | 播放控件、字幕和步骤定位明显 | 语音讲解、思路口述、步骤旁白 |
| R 阅读书写型 | 概念、条件、推导、结论分层排版 | 文字步骤、要点清单、笔记总结 |
| K 动觉实操型 | 讲解区域缩短，练习和反馈占主要空间 | 变式练习、案例题、即时试错 |

混合型在同一页面组合两种资源。VK 型应同时出现示意图和实操变式练习，但不能堆叠两套完整页面。

## 4 教师端和管理端页面

| 页面 | 内容 |
| --- | --- |
| 教师端班级统计 | 控制感分布、题目认知负荷分布、VARK 分布、已评估人数、主动求助数量 |
| 教师端学生档案 | VARK 结果和历史、轮后自评原始答案、控制感等级、感知负荷、适配决策 |
| 管理端统计 | 跨班级统计和筛选 |
| 管理端学生档案 | 完整历史和规则版本 |
| 题库管理 | 单题编辑、筛选和批量设置认知负荷 |
| 系统设置 | 白名单、VARK 有效期、阈值、规则版本和便利贴文案 |
