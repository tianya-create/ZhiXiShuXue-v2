# 智析数学技术栈和开发环境说明

## 1 系统结构

系统采用前后端分离架构。前端通过 HTTP API 与后端交互，后端负责身份鉴权、题库、学习闭环、适配规则、统计和持久化。开发环境前端端口为 5000，后端端口为 5001。

## 4 新增数据集合

| 集合 | 说明 |
| --- | --- |
| `varkAssessments` | 保存问卷原始答案、四维分数、单一或双偏好和有效期 |
| `learningRounds` | 保存有效 5 题轮次、正确率、知识点、任务复杂度和请求 ID |
| `controlAssessments` | 保存表情、Q1、Q2、Q3、控制感和感知负荷结果 |
| `adaptationDecisions` | 保存复杂度调整、支架、页面密度、原因码和规则版本 |
| `presentationEvidence` | 保存资源呈现和长期学习效果证据 |
| `teacherSupportRequests` | 保存学生主动向教师求助的请求 |

## 5 主要新增接口

| 角色 | 接口 | 用途 |
| --- | --- | --- |
| 学生 | `GET /api/student/adaptation/status` | 检查 VARK 是否到期和是否有待完成自评 |
| 学生 | `GET /api/student/vark/questionnaire` | 获取 VARK 问卷和量表选项 |
| 学生 | `POST /api/student/vark/assessments` | 提交 VARK 并返回学生可见结果 |
| 学生 | `POST /api/student/practice/:knowledgePointId/submit` | 原子提交 5 题任务包 |
| 学生 | `POST /api/student/learning-rounds/:id/reflection` | 提交轮后自评并生成适配决策 |
| 学生 | `POST /api/student/support-requests` | 主动向教师求助 |
| 教师 | `GET /api/teacher/adaptation/overview` | 查看班级适配统计 |
| 教师 | `GET /api/teacher/adaptation/students/:studentId/history` | 查看学生完整适配历史 |
| 管理员 | `GET /api/admin/adaptation/overview` | 查看跨班级统计 |
| 管理员 | `GET /api/admin/adaptation/students/:studentId/history` | 查看学生完整历史 |

## 6 开发环境和运行方式

1. 在项目根目录执行 `npm install` 安装前后端依赖。
2. 按需复制 `backend/.env.example` 为 `backend/.env`。
3. 在根目录执行 `npm run dev` 同时启动前后端。
4. 前端访问地址为 `http://localhost:5000`。
5. 后端健康检查地址为 `http://localhost:5001/api/health`。
6. 在 `backend` 目录执行 `npm test` 运行 Jest 测试。

演示账号：管理员 `admin/admin123`，教师 `teacher/teacher123`，学生 `student/student123`，另有 `student2` 至 `student10`。

## 7 部署和数据说明

题库和业务数据保存在 SQLite，服务重启后不应重置。生产环境必须配置独立的 JWT 密钥，按部署手册设置环境变量，并备份数据库和上传目录。OCR 和大模型服务为可选配置，不影响双层适配核心闭环。
